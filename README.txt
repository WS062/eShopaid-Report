BUILD OPTION A - GitHub (no install needed)
1. Create a free account at github.com -> New repository (e.g. AlkhamisPOS).
2. 'uploading an existing file' -> drag ALL contents of this folder (including .github) -> Commit.
3. Open the 'Actions' tab -> 'Build APK' runs automatically (~4 min).
4. Click the finished run -> download 'AlkhamisPOS-apk' -> unzip -> app-release.apk.

BUILD OPTION B - Android Studio
Open this folder in Android Studio -> Build -> Build APK(s).

INSTALL: copy the APK to the phone, open it, allow 'Install unknown apps'.
